## 🎯 معرفی پروژه

این پروژه شامل دو اسکریپت Bash قدرتمند برای همگام‌سازی یادداشت‌های **Obsidian** با استفاده از **Git** و **GitHub** است. این اسکریپت‌ها به شما اجازه می‌دهند یادداشت‌های خود را بین کامپیوتر (Ubuntu/Linux) و گوشی اندروید به‌صورت امن و رایگان همگام کنید.

### چرا این اسکریپت‌ها؟

| ویژگی | توضیح |
|--------|--------|
| 🆓 **کاملاً رایگان** | بدون نیاز به سرویس‌های پولی مثل Obsidian Sync |
| 🔒 **امن** | استفاده از Git و SSH برای انتقال امن |
| 🎮 **کنترل کامل** | بدون conflict خودکار، تصمیم‌گیری با شماست |
| 🚀 **سریع** | یک دستور برای تمام عملیات |
| 💾 **بکاپ خودکار** | بکاپ‌های منظم و قابل بازیابی |

## ✨ ویژگی‌ها

### 💻 اسکریپت کامپیوتر (`obsidian-sync`)

```bash
# دستورات موجود:
obsidian-sync          # Sync کامل (Pull + Push)
obsidian-sync pull     # فقط دریافت تغییرات از GitHub
obsidian-sync push     # فقط ارسال تغییرات به GitHub
obsidian-sync status   # نمایش وضعیت کامل Repository
obsidian-sync info     # اطلاعات کامل Vault (تعداد فایل، حجم)
obsidian-sync backup   # بکاپ فوری در فایل tar.gz
obsidian-sync help     # نمایش راهنمای کامل
```

**ویژگی‌های خاص:**
- ✅ مدیریت خودکار Conflict با Rebase
- ✅ بکاپ خودکار با حذف بکاپ‌های قدیمی (بیش از ۷ روز)
- ✅ نمایش وضعیت کامل (فایل‌های تغییر کرده، commitهای local/remote)
- ✅ تنظیم اولیه Git در صورت عدم وجود Repository

### 📱 اسکریپت موبایل (`ob-sync`)

```bash
# دستورات موجود:
ob-sync          # Sync کامل (Pull + Push)
ob-sync pull     # فقط دریافت تغییرات از GitHub
ob-sync push     # فقط ارسال تغییرات به GitHub
ob-sync status   # نمایش وضعیت Repository
ob-sync help     # نمایش راهنما
```

**ویژگی‌های خاص:**
- ✅ Pull ایمن بدون ریسک از دست رفتن داده
- ✅ Push کنترل‌شده با تأیید
- ✅ مدیریت Conflict با راهنمای گام‌به‌گام
- ✅ سازگار کامل با Termux

## 📋 پیش‌نیازها

### برای کامپیوتر (Ubuntu/Linux):

```bash
# ۱. به‌روزرسانی سیستم
sudo apt update && sudo apt upgrade -y

# ۲. نصب Git
sudo apt install git -y

# ۳. ساخت SSH Key (اگر ندارید)
ssh-keygen -t ed25519 -C "your_email@example.com"

# ۴. نمایش کلید عمومی
cat ~/.ssh/id_ed25519.pub

# ۵. اضافه کردن کلید به GitHub:
#    GitHub → Settings → SSH and GPG keys → New SSH key

# ۶. تست اتصال
ssh -T git@github.com
# باید پیام: "Hi YourUsername! You've successfully authenticated"

# ۷. نصب Obsidian
# از https://obsidian.md/download دانلود و نصب کنید
```

### برای موبایل (Android):

```bash
# ۱. نصب Termux از F-Droid (توصیه می‌شود)
# https://f-droid.org/packages/com.termux/

# ۲. در Termux، به‌روزرسانی:
pkg update && pkg upgrade -y

# ۳. نصب پکیج‌های ضروری:
pkg install git openssh -y

# ۴. فعال‌سازی دسترسی به حافظه:
termux-setup-storage
# روی "Allow" بزنید

# ۵. تنظیم Git:
git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"
git config --global --add safe.directory "*"
git config --global credential.helper store
git config --global pull.rebase true

# ۶. ساخت SSH Key برای گوشی:
ssh-keygen -t ed25519 -C "mobile-phone" -f ~/.ssh/id_ed25519 -N ""

# ۷. نمایش کلید:
cat ~/.ssh/id_ed25519.pub
# این کلید را به GitHub اضافه کنید (با عنوان "Mobile Phone")
```

### برای GitHub:

1. **ساخت Repository خصوصی** برای یادداشت‌ها:
   - GitHub → New Repository
   - Name: `obsidian` (یا هر نام دلخواه)
   - Private ✅
   - Initialize with README ❌ (خودمان می‌سازیم)

2. **ساخت Personal Access Token (PAT)** برای موبایل:
   - GitHub → Settings → Developer settings → Personal access tokens
   - Generate new token (classic)
   - Scopes: `repo` ✅
   - **کپی و ذخیره کنید** (فقط یک‌بار نمایش داده می‌شود!)

## 💻 نصب اسکریپت کامپیوتر

### روش ۱: دانلود مستقیم (توصیه می‌شود)

```bash
# ۱. دانلود اسکریپت
wget https://raw.githubusercontent.com/CheginiSoroush/obsidian-sync-scripts/main/desktop/obsidian-sync -O ~/obsidian-sync

# ۲. تنظیم مجوز اجرا
chmod +x ~/obsidian-sync

# ۳. ایجاد Alias برای دسترسی سریع
echo 'alias obsidian-sync="$HOME/obsidian-sync"' >> ~/.bashrc

# ۴. اعمال تغییرات
source ~/.bashrc

# ۵. تست
obsidian-sync help
```

### روش ۲: کلون کامل ریپازیتوری

```bash
# ۱. کلون ریپازیتوری
git clone https://github.com/CheginiSoroush/obsidian-sync-scripts.git ~/obsidian-sync-repo

# ۲. کپی اسکریپت به Home
cp ~/obsidian-sync-repo/desktop/obsidian-sync ~/obsidian-sync
chmod +x ~/obsidian-sync

# ۳. ایجاد Alias
echo 'alias obsidian-sync="$HOME/obsidian-sync"' >> ~/.bashrc
source ~/.bashrc
```

### روش ۳: نصب دستی

```bash
# ۱. ساخت فایل
nano ~/obsidian-sync

# ۲. محتوای اسکریپت را کپی و Paste کنید

# ۳. ذخیره و خروج
# Ctrl+O → Enter → Ctrl+X

# ۴. تنظیم مجوز
chmod +x ~/obsidian-sync

# ۵. ایجاد Alias
echo 'alias obsidian-sync="$HOME/obsidian-sync"' >> ~/.bashrc
source ~/.bashrc
```

### تنظیمات اولیه:

```bash
# ۱. تنظیم Git (اگر قبلاً انجام نداده‌اید)
git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"

# ۲. تنظیم مسیر Vault (در صورت نیاز)
# فایل اسکریپت را ویرایش کنید:
nano ~/obsidian-sync
# خط زیر را پیدا و تغییر دهید:
# VAULT_PATH="/media/sss/shared/obsidian"
# به مسیر دلخواه شما

# ۳. راه‌اندازی Git در Vault (اگر .git ندارید)
cd /path/to/your/vault
git init
git remote add origin https://github.com/YourUsername/obsidian.git
git fetch origin
git checkout -b main
git branch --set-upstream-to=origin/main main

# ۴. تست اسکریپت
obsidian-sync status
```

## ⚙️ تنظیمات پیشرفته

### تغییر مسیر Vault:

**کامپیوتر:**
```bash
# ۱. فایل اسکریپت را باز کنید:
nano ~/obsidian-sync

# ۲. خط زیر را پیدا کنید:
# VAULT_PATH="/media/sss/shared/obsidian"

# ۳. به مسیر دلخواه تغییر دهید:
VAULT_PATH="/your/custom/path/to/vault"

# ۴. ذخیره: Ctrl+O → Enter → Ctrl+X
```

**موبایل:**
```bash
# ۱. فایل اسکریپت را باز کنید:
nano ~/ob-sync

# ۲. خط زیر را پیدا کنید:
# VAULT="$HOME/storage/shared/Documents/Soroush"

# ۳. به مسیر دلخواه تغییر دهید:
VAULT="/your/custom/path/to/vault"
```

### تنظیم Sync خودکار (Cron Job):

```bash
# کامپیوتر - هر ۳۰ دقیقه Sync خودکار:
(crontab -l 2>/dev/null; echo "*/30 * * * * $HOME/obsidian-sync") | crontab -

# کامپیوتر - بکاپ روزانه ساعت ۲ صبح:
(crontab -l 2>/dev/null; echo "0 2 * * * $HOME/obsidian-sync backup") | crontab -

# کامپیوتر - بکاپ هفتگی (یک‌شنبه‌ها):
(crontab -l 2>/dev/null; echo "0 3 * * 0 $HOME/obsidian-sync backup") | crontab -

# بررسی Cron Jobs:
crontab -l
```

### تنظیم SSH برای امنیت بیشتر:

```bash
# ۱. ساخت SSH Key (اگر ندارید):
ssh-keygen -t ed25519 -C "your_email@example.com"

# ۲. اضافه کردن کلید به ssh-agent:
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

# ۳. تنظیم SSH Config برای GitHub:
cat >> ~/.ssh/config << 'EOF'
Host github.com
  Hostname ssh.github.com
  Port 443
  User git
  IdentityFile ~/.ssh/id_ed25519
EOF

# ۴. تغییر Remote از HTTPS به SSH:
cd /path/to/vault
```

## 🔧 عیب‌یابی

### مشکل: `Permission denied (publickey)`

```bash
# راه‌حل:
# ۱. بررسی اجرا بودن ssh-agent:
eval "$(ssh-agent -s)"

# ۲. اضافه کردن کلید:
ssh-add ~/.ssh/id_ed25519

# ۳. تست:
ssh -T git@github.com

# ۴. اگر کار نکرد، کلید عمومی را به GitHub اضافه کنید:
cat ~/.ssh/id_ed25519.pub
# GitHub → Settings → SSH and GPG keys → New SSH key
```

### مشکل: `Repository not found`

```bash
# ۱. بررسی Remote:
cd /path/to/vault
git remote -v

# ۲. اصلاح Remote:
git remote set-url origin git@github.com:YourUsername/obsidian.git

# ۳. تست:
git fetch origin
```

### مشکل: `merge conflict`

```bash
# راه‌حل برای کامپیوتر:
obsidian-sync pull

# اگر حل نشد:
cd /path/to/vault
git rebase --abort
git fetch origin
git reset --hard origin/main

# راه‌حل برای موبایل:
cd ~/storage/shared/Documents/Soroush
git rebase --abort 2>/dev/null
git fetch origin
git reset --hard origin/main
```

### مشکل: `detected dubious ownership`

```bash
# راه‌حل:
git config --global --add safe.directory "*"
```

### مشکل: `index file too small`

```bash
# راه‌حل (بازسازی Git):
cd /path/to/vault

# ۱. بکاپ از فایل‌ها:
tar -czf ~/vault-backup-$(date +%Y%m%d).tar.gz -C . .

# ۲. حذف Git:
rm -rf .git

# ۳. راه‌اندازی مجدد:
git init
git remote add origin https://github.com/YourUsername/obsidian.git
git fetch origin
git checkout -b main
git branch --set-upstream-to=origin/main main
git pull origin main
```

### مشکل: `Author identity unknown`

```bash
# راه‌حل:
git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"
```

### مشکل: درایو مشترک Mount نمی‌شود (Dual Boot)

```bash
# ۱. بررسی UUID:
sudo blkid

# ۲. تنظیم fstab:
sudo nano /etc/fstab
# اضافه کنید:
# UUID=xxxx-xxxx /mnt/shared ntfs-3g defaults,uid=1000,gid=1000,umask=007 0 0

# ۳. Mount:
sudo mount -a

# ۴. تغییر مسیر در اسکریپت:
nano ~/obsidian-sync
# VAULT_PATH="/mnt/shared/obsidian"
```

## ❓ سوالات متداول

### Q: آیا این سیستم رایگان است؟

**A:** بله، کاملاً رایگان! فقط از GitHub (برای Repository خصوصی) و Git استفاده می‌شود.

### Q: آیا داده‌های من امن هستند؟

**A:** بله:
- Repository شما **Private** است
- انتقال با **SSH** رمزنگاری شده
- Git تاریخچه کامل دارد (می‌توانید به عقب برگردید)

### Q: اگر همزمان در دو دستگاه بنویسم چه می‌شود؟

**A:** **نکنید!** این باعث conflict می‌شود. قانون طلایی:
1. در یک دستگاه بنویسید
2. Push کنید
3. در دستگاه دیگر Pull کنید
4. سپس بنویسید

### Q: چقدر فضا در GitHub اشغال می‌شود؟

**A:** GitHub برای Repository خصوصی:
- **حجم کل:** تا ۱ گیگابایت (رایگان)
- **فایل تک:** حداکثر ۱۰۰ مگابایت
- **توصیه:** فایل‌های ویدیویی را جدا نگه دارید

### Q: آیا می‌توانم فایل‌های تصویری هم ذخیره کنم؟

**A:** بله، اما:
- فایل‌های < 50MB مشکلی ندارند
- فایل‌های بزرگ را در پوشه جدا بگذارید
- می‌توانید در `.gitignore` اضافه کنید

### Q: اگر Termux را حذف کنم چه می‌شود؟

**A:**
- اسکریپت و تنظیمات حذف می‌شوند
- Vault (فایل‌های Obsidian) در Documents باقی می‌ماند
- فقط Termux را دوباره نصب و اسکریپت را اجرا کنید

### Q: چطور بکاپ بگیرم؟

**A:**
```bash
# کامپیوتر:
obsidian-sync backup

# دستی:
tar -czf backup-$(date +%Y%m%d).tar.gz -C /path/to/vault .

# بازیابی:
tar -xzf backup-YYYYMMDD.tar.gz -C /path/to/vault
```

### Q: آیا روی iOS هم کار می‌کند؟

**A:** خیر، این اسکریپت‌ها فقط برای **اندروید** (Termux) و **Linux** هستند. برای iOS می‌توانید از [a-Shell](https://apps.apple.com/us/app/a-shell/id1473805438) استفاده کنید.

### Q: چطور Conflict را حل کنم؟

**A:** اسکریپت راهنمایی می‌کند:
1. فایل‌های conflict دار را باز کنید
2. علامت‌های `<<<<<<<`، `=======`، `>>>>>>>` را پیدا کنید
3. محتوای مورد نظر را نگه دارید
4. علامت‌ها را حذف کنید
5. دوباره push کنید
